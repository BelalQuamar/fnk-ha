# FNK_HA v0.3

- Long entity names use two lines. Each line scrolls independently when it exceeds the tile width, while the status badge stays in place.
- The header shows the local time and date. The clock follows Home Assistant's configured timezone and daylight-saving rules.
- A compact footer holds the circular Refresh icon, larger page arrows, and the wider view selector.
- The view selector now includes **Settings**, which shows Wi-Fi status and signal strength, the FNK and server IP addresses, Home Assistant connection status, the firmware version, and timezone.

Use the app-only binary at **0x10000** to update an existing FNK_HA installation and keep your settings. Use the merged binary at **0x0** for a fresh installation. The merged image clears saved settings. See INSTALL.md for flashing and setup.
