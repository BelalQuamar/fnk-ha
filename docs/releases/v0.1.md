# FNK_HA v0.1

Initial firmware release for the Freenove FNK0104B 2.8-inch ESP32-S3 display.

- Connects over local Wi-Fi to Home Assistant.
- Displays Home Assistant entities in an adaptive grid with up to nine tiles per page.
- Discovers entities on startup and refreshes the list and their states every 60 seconds.
- Supports touch controls for lights, switches, fans, humidifiers, and input booleans.
- Includes USB setup, a clock, and automatic screen sleep.

Use the merged binary for a fresh installation or the app binary to update an existing FNK_HA installation. See INSTALL.md for flash offsets and setup.
