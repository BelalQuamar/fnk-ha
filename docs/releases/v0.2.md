# FNK_HA v0.2

This release gives entity names more room on the Freenove FNK0104B display. The grid uses up to two columns and six tiles per page. Names use larger white type and wrap or scroll as needed. Separate color-coded badges show each entity's reported state.

- **Controls** shows supported on/off entities by default. **All** shows every reported entity, and **Favorites** shows a custom list that you can pin and reorder on the display.
- The compact header holds the clock, view selector, and **Refresh** button. Page navigation appears along the bottom when the current view spans multiple pages.
- The entity list and states still refresh automatically every 60 seconds.

Use the merged binary at **0x0** for a fresh installation. It clears existing settings. For an existing FNK_HA installation, use the app binary at **0x10000** to keep your Wi-Fi and Home Assistant configuration. See INSTALL.md for flashing and setup.
