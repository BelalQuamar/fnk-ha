# FNK_HA v0.3.1

Home Assistant buttons, including Wake-on-LAN buttons and button helpers, now work from **All** and **Favorites**. Available buttons show a **Press** badge in place of the last-pressed timestamp. Home Assistant acknowledges the action without reporting the target computer's power state.

Use the app-only binary at **0x10000** to update FNK_HA and keep saved settings. Use the merged binary at **0x0** for a fresh install. It clears saved settings. See INSTALL.md for flashing and setup.
